# 📊 AI Data Insight Builder

> **"숫자 계산은 100% Pandas가, 데이터 해석과 스토리는 Gemini AI가"**  
> 신뢰할 수 있는 통계 분석과 친절한 자연어 해석을 결합한 교육·연구용 데이터 시각화 & 인사이트 웹 애플리케이션입니다.

---

## 💡 프로젝트 기획 배경 및 철학

기존 생성형 AI는 그럴듯하지만 계산이 틀리거나 존재하지 않는 숫자를 지어내는 **환각(Hallucination)** 문제가 빈번합니다. 특히 통계 분석에서 AI에게 직접 연산을 맡기면 데이터 왜곡이 발생합니다.

**AI Data Insight Builder**는 다음과 같은 확고한 원칙으로 설계되었습니다:
1. **엄격한 역할 분리**: 모든 숫자 계산, 순위 정렬, 결측치 필터링은 **100% Python Pandas**가 수행합니다. Gemini AI는 단 1건의 연산도 직접 하지 않습니다.
2. **환각 검증 보고서 (모드 B)**: 엄격한 8대 해석 규칙을 준수하여, Pandas 계산 결과에 존재하는 숫자만을 근거로 사실 기반 해석 보고서를 작성합니다.
3. **가벼운 스택, 높은 신뢰도**: 복잡한 빌드 도구나 무거운 DB 없이, 순수 웹 표준(Vanilla JS, HTML/CSS)과 경량 Flask 백엔드로 빠르고 직관적인 탐색 환경을 제공합니다.

## ✨ 핵심 기능

### 1. 🔍 CSV 정밀 자동 진단 (`/inspect`)
- CSV 파일 업로드 시 상단 메타데이터/공백 자동 탐색 및 건너뛰기 (`skiprows` 자동 감지)
- 인코딩 자동 감지 (`utf-8`, `cp949`, `euc-kr` 등)
- 결측치 비율, 중복 행, 유령 열(Unnamed) 감지
- 세계은행/국제기구 데이터셋 특유의 **지역/소득 그룹 집계 행(World, OECD, Low income 등) 자동 탐지 및 분리**
- 데이터 충실도가 가장 높은 **권장 기준연도(recommended_year) 자동 추천**

### 2. 🛠️ 12대 결정론적 분석 도구 카탈로그 (`/run`)
| 번호 | 도구 ID | 도구명 | 설명 |
| :---: | :--- | :--- | :--- |
| **01** | `wide_to_long` | 와이드-롱 구조 변환 | 가로로 펼쳐진 연도별 열을 시계열 분석에 적합한 롱 포맷으로 재구조화 |
| **02** | `quality_report` | 데이터 품질 정밀 진단 | 결측·중복·타입·유령 열을 전수 진단 |
| **03** | `detect_aggregates` | 집계 행 vs 개별 국가 분리 | 국가 간 비교 왜곡을 방지하기 위해 비국가 집계 행을 정밀 추출 |
| **04** | `recommend_reference_year` | 최적 기준연도 추천 | 결측치를 최소화하는 대표 연도 자동 선별 |
| **05** | `simple_summary` | 기초 통계 요약 | 평균, 중앙값, 최솟값, 최댓값, 표준편차 계산 |
| **06** | `filter_scope` | 분석 대상 스코프 필터링 | 분석 목적에 맞는 서브셋 분리 |
| **07** | `top_bottom_n` | 상위·하위 N 순위 분석 | 최상위/최하위 N개국 순위 및 **타깃 국가(대한민국) 자동 비교 표기** |
| **08** | `change_rate` | 시계열 증감률 비교 | 두 시점 간의 증감률(%) 및 변화량 분석 |
| **09** | `compare_one_vs_all` | 특정 대상 vs 전체 집단 비교 | 특정 국가의 위치를 전체 분포와 백분위수로 비교 |
| **10** | `gap_analysis` | 1위 대비 격차 분석 | 선두 그룹과의 수치 격차 정량 분석 |
| **11** | `distribution_histogram` | 데이터 분포 히스토그램 | 구간별 빈도 분포 분석 |
| **12** | `trend_line` | 연도별 시계열 추세 분석 | 장기 트렌드 시각화 |

### 3. 🤖 스마트 AI 질문 & 라우팅 (`/ask`)
- 사용자가 *"2024년에 한국은 몇 위야?"* 같은 자연어 질문을 입력하면, 질문 의도를 즉시 파악하여 데이터 요약 설명과 함께 가장 적합한 분석 도구(예: `top_bottom_n`, `target_item: Korea, Rep.`)를 자동으로 매핑하고 실행 버튼을 제공합니다.

### 4. 📝 2가지 모드의 AI 인사이트 보고서 (`/explain`)
- **모드 A (비교용)**: 원본 데이터셋 요약만 보고 작성하여 환각 발생 위험을 체험할 수 있는 모드.
- **모드 B (정식 보고서)**: 오직 Pandas 계산 결과만을 엄격히 바탕으로 작성. 기준 시점, 제외된 행 수와 사유, 인터넷 이용자 공식 정의를 명시하며 지어낸 숫자가 전무(0개)함을 보장.

### 5. 📊 정밀 반응형 차트 (Chart.js)
- 상위 국가와 타깃 국가(대한민국)를 서로 다른 색상(`오렌지`)으로 구분 강조
- 각 막대 상단에 실제 수치 데이터 레이블 자동 표시
- 최상위 국가들 간의 미세한 차이를 극대화하여 관찰하는 **[🔍 차이 돋보기 확대 모드 (95%~100%)]**와 전체 비율을 보는 **[🌐 전체 비율 모드 (0%~100%)]** 원클릭 토글 지원

### 6. 🔒 4자리 PIN 게이트 & 24시간 보안 세션
- 무단 접근을 방지하는 4자리 PIN 잠금 화면 (`0110`)
- Flask 서버 측 암호 검증 및 24시간 영구 세션(`Permanent Session`) 관리
- 브라우저를 닫았다가 다시 열어도 24시간 동안 로그인 유지, 로그아웃 시 메모리 데이터셋 완전 소각

## 🛠️ 기술 스택

- **Backend**: Python 3.11+, Flask
- **Data & AI**: Pandas, NumPy, Google Gemini API (`google-genai`), Python-dotenv
- **Frontend**: Vanilla JavaScript (ES6+), HTML5, Plain CSS3 (반응형, 모던 UI)
- **Libraries**: Chart.js 4.4, chartjs-plugin-datalabels, Marked.js (마크다운 렌더링)
- **Version Control**: Git

## 🚀 빠른 시작 가이드 (Quick Start)

### 1. 레포지토리 복제 및 가상환경 설정
```powershell
# 프로젝트 디렉터리 이동
cd C:\AI-study\data-insight-builder

# 가상환경 활성화 (Windows PowerShell 기준)
.\.venv\Scripts\Activate.ps1
```

### 2. 패키지 설치
```powershell
pip install -r requirements.txt
```

### 3. 환경 변수(`.env`) 설정
프로젝트 루트 디렉터리에 `.env` 파일을 생성하고 다음 변수를 입력합니다:
```env
GEMINI_API_KEY=your_gemini_api_key_here
FLASK_SECRET_KEY=your_secret_key_here
APP_PIN=0110
```

### 4. 서버 실행
```powershell
python app.py
```
서버가 기동되면 웹 브라우저에서 `http://127.0.0.1:5000`으로 접속합니다.

## 📖 사용 흐름

1. **로그인**: 보안 PIN `0110`을 입력하여 접속합니다.
2. **데이터 업로드**: 분석하고자 하는 CSV 파일(예: 세계은행 인터넷 이용률 데이터)을 드래그하거나 선택하여 업로드합니다.
3. **데이터 정밀 진단**: 상단 요약 카드와 권장 기준연도, 제외 집계행 목록을 확인합니다.
4. **자연어 질의 또는 도구 실행**: 
   - 질문창에 궁금한 점을 입력하여 최적 분석을 추천받거나,
   - 12대 분석 도구 목록에서 원하는 도구를 선택해 실행합니다.
5. **차트 및 테이블 확인**: 차트 돋보기 모드와 데이터 테이블을 통해 분석 결과를 확인합니다.
6. **모드 B 보고서 생성**: 하단의 `[📘 모드 B: 정식 판다스 기반 보고서]` 버튼을 클릭하여 엄격하게 검증된 사실 기반 보고서를 확인합니다.
